# Security

Satsuma watches the mouse and opens files people drag onto it, so security reports matter a lot to me.

## Reporting a problem

Please report it privately through
[GitHub's security advisories](https://github.com/jpizzzel/tangerineforwindows/security/advisories/new)
instead of opening a public issue. Include what you found, how to reproduce it, and what someone could do with it.

I'll reply as soon as I can, keep you posted while I fix it, and credit you in the release notes if you'd like.

## What's in scope

- The Windows app (anything under `src/`)
- The release zips on the Releases page
- The website and its download functions (`site/`)

Only the latest release gets security fixes.
